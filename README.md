# Food Cart Website

A modern responsive food cart website built using React , Vite and Tailwind CSS. User can browse food items filter categories search products and manage cart seamlessly.

## Features

- Responsive design
- Multi Pages
- Product filtering
- Search functionality
- Add to cart
- LocalStorage cart persistence
- Contact form validation

## Tech Stack & Libraries

- React JS (Vite)
- JavaScript
- Tailwind CSS
- React Router
- Swiper js
- Formspree

## Installation

```bash
npm install
npm run dev
```
